# PokeProBot

Bot for **Pokémon Revolution Online (PRO)**.

**Download:** [Setup_PokeProBot.exe](https://github.com/GabesBarbosa/PokeProBot-releases/releases/latest/download/Setup_PokeProBot.exe) (Windows 10/11, 64-bit)

## English
1. Download and run `Setup_PokeProBot.exe`.
2. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
3. Open Pokémon Revolution Online in windowed mode (Alt+Enter), then open PokeProBot and sign in with the account you received after purchase.

## Português
1. Baixe e execute o `Setup_PokeProBot.exe`.
2. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. Abra o Pokémon Revolution Online em modo janela (Alt+Enter), depois abra o PokeProBot e entre com a conta que você recebeu na compra.

Updates: download the latest installer from this page and run it again. Your settings are kept.
Atualizações: baixe o instalador mais recente nesta página e execute de novo. Suas configurações são mantidas.
